完整硬件监控组件说明

安装程序默认选择“安装完整硬件监控组件”。该组件用于读取 CPU 温度、主板传感器等需要底层硬件访问权限的指标。

选择该组件会安装：

1．PawnIO 2.1 硬件访问驱动。这是由 namazso 提供的共享系统驱动，其他硬件监控或风扇控制软件也可能使用它。

2．UniDesk Hardware Monitoring Service。该 Windows 服务以 LocalSystem 账户运行，只通过本机命名管道向 UniDesk 返回只读传感器快照，不提供任意命令执行能力，也不监听网络端口。

UniDesk 主程序仍以当前登录用户的普通权限运行，不会因为启用该组件而始终以管理员身份运行。安装程序本身需要管理员权限，仅用于写入 Program Files、安装驱动和注册系统服务。

请直接双击安装包并在 Windows 提示时确认 UAC；标准用户需要输入管理员凭据。无需右键选择“以管理员身份运行”。安装完成页默认勾选启动 UniDesk，安装程序会使用安装前的普通用户身份自动启动主程序。

如果不接受安装驱动或系统服务，请在后续“选择附加任务”页面取消勾选“安装完整硬件监控组件”。取消或组件因安全策略、驱动兼容性等原因安装失败后，UniDesk 的其他功能仍可使用，但部分电脑可能无法显示 CPU 温度等指标；可稍后从设置中导出诊断并重试修复。

卸载 UniDesk 时会删除 UniDesk 自有的硬件监控服务；共享的 PawnIO 驱动默认保留，卸载程序会另行询问是否同时移除。

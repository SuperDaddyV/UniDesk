## 正式制品身份与门禁

正式发布必须从精确、干净的公开 `main` 提交重建。最终提交、安装包大小及 SHA-256 以同一 GitHub Release 的 `release-manifest.json` 和 `SHA256SUMS.txt` 为准；本地候选哈希不能用作正式包哈希。

| ID | 要求 | 记录规则 |
| --- | --- | --- |
| AU-01 | SDK `10.0.302`、`win-x64` 锁定还原、版本一致性、依赖漏洞检查 | 发布前对最终公开提交执行，实际结果见同页 Release |
| AU-02 | 零警告／零错误 Release 构建；`dotnet test UniDesk.sln -c Release --no-restore` | 发布前对最终公开提交执行，实际测试计数见同页 Release |
| AU-03 | 精确公开 `main` 提交的 GitHub CI 成功 | 发布前确认成功，提交与 CI 链接见同页 Release |
| RS-01 | 干净源码、schema 3 来源清单、载荷目录与全部文件哈希 | 发布前校验正式载荷，来源清单指纹见 `release-manifest.json` |

Windows 可能显示 SmartScreen 或企业策略提示；公开下载说明必须保留 `Authenticode: NotSigned` 声明。

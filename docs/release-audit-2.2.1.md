状态：**已转为发布后风险接受与流程整改，不再构成下架条件。**

`v2.2.1` 发布时，测试矩阵的 CI、制品和人工项目仍未更新，且停止条件规定人工矩阵未完成时不得创建或更新 Release。这一流程不符合项是真实历史，不能通过事后宣称“发布前已完成”来抹除。本轮采取的修订是：

### P2：后续维护项

- 公开 `release-manifest.json` 只发布源清单 SHA-256 和 10 项制品摘要，不自包含 schema 3 的 SDK、锁文件及 1,431 项载荷清单。当前 Release 不替换资产；下一版本改进公开清单契约。
- 硬件命名管道客户端未验证服务端 PID、SCM 服务归属、映像路径或服务身份。同一普通用户可在服务未监听时抢占同名管道并伪造遥测或健康响应；未发现提权或任意命令路径，进入后续安全维护。
- 服务停止查询将“服务不存在”和部分 `Get-Service` 查询失败都折叠为 `$null`，罕见 SCM／查询失败可能产生 fail-open；进入后续维护。
- 天气缓存、搜索和部分备份／快捷方式读取路径仍存在持久化失败被吞掉、返回部分结果或非法枚举被默认值替代的情况；进入后续数据一致性维护。
- GitHub 主分支审批数为 0，签名环境允许 self-review，仓库 `allowed_actions=all` 且未强制 SHA pinning；当前 workflow 实际 Action 引用均固定到完整 SHA，因此属于后续治理增强。
